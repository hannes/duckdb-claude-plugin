Use the duckdb command line tool, which is installed, to compute two things and report both numbers: the sum of the squares of the integers 1 to 100, and the number of elements greater than 2 in the list [1, 2, 3, 4, 5] computed with list_filter. Run the queries; do not just reason about them.
